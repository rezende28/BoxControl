# 📦 BoxControl

Sistema web para gerenciamento e controle de caixas.

## 📌 Sobre o projeto

O BoxControl é um sistema desenvolvido para facilitar o controle e acompanhamento de caixas armazenadas, permitindo organizar informações, acompanhar status e manter um histórico dos registros.

O projeto nasceu a partir da necessidade de transformar um processo manual em uma solução digital mais organizada, possibilitando maior controle, rastreabilidade e facilidade de consulta.

## ✨ Funcionalidades

✅ Cadastro de caixas  
✅ Geração automática do código da caixa  
✅ Controle de unidades  
✅ Controle de mês/ano das caixas  
✅ Identificação do responsável pelo cadastro  
✅ Registro automático da data e hora do cadastro  
✅ Controle de status das caixas  
✅ Alteração de status para caixas prontas  
✅ Seleção de caixas para envio  
✅ Registro automático da data e hora do envio  
✅ Histórico de caixas enviadas  
✅ Exclusão de registros
